What this tool does

GifToFrames extracts full display frames from animated GIF files, including GIFs that use transparency, local frame rectangles, varied frame delays, and disposal methods. Exported files use ordered names such as animation_frame_0001.png.

Use it only with GIFs you own or are authorized to process. It does not fetch third-party URLs, bypass protected media, create public result pages, or store uploaded files.
