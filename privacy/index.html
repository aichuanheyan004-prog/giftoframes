Privacy

Privacy

Last updated: July 27, 2026.

GIF processing

GifToFrames processes selected GIF files in your browser. The GIF file, decoded frame pixels, file name, and exported frame images are not uploaded to a GifToFrames conversion server, database, analytics tool, or error logging service.

Temporary browser data

While you use the tool, your browser stores the selected file and generated frames in memory. It may create temporary object URLs for downloads and previews. Resetting the tool clears the current frame data and revokes temporary object URLs created by the app.

Static hosting

GifToFrames is a static website. The hosting provider receives ordinary web requests for pages and assets such as JavaScript, CSS, favicon, robots.txt, sitemap.xml, and the sample GIF. Those requests can include information such as IP address, user agent, referrer, URL path, timestamp, and response status according to the hosting provider's infrastructure logs.

Analytics and cookies

Version one does not include analytics, advertising pixels, account cookies, or third-party upload services. If analytics are added later, they must not include GIF names, GIF bytes, frame pixels, exported images, or other file contents.

Contact

For privacy or removal concerns, contact the site owner through the repository or hosting account associated with this project.
